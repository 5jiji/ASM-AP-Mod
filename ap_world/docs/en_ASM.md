# A Solitaire Mystery

## Where is the options page?

The [player options page for this game](../player-options) contains all the options you need to configure and export a
config file.

## What is A Solitaire Mystery?

From the steam page:
> A collection of mysterious solitaires. The solitaires included vary from fairly standard cardgames to funky reimplementations of other games in solitaire form.

This game contains 30 different solitaire modes, all of which becomes items in this Archipelago mod.
